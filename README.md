# say to draw – Android

Černé plátno, které poslouchá a kreslí, co se mu řekne. Kreslí vlastním kurzorem
s lidským pohybem.

## Stažení

**[⬇ Nejnovější verze (APK)](https://github.com/ItzStepix/say-to-draw-apk/releases/latest)**

1. Otevři odkaz v telefonu a stáhni soubor `.apk`.
2. Otevři ho a povol instalaci z prohlížeče.
3. Při prvním spuštění povol mikrofon.

## Ovládání

- řekni **„nakresli kočku“**, **„nakresli modré auto“**, **„udělej barvy“**, **„smaž to“**
- ťukni = napsat zadání, podrž = smazat
- 71 ručně nakreslených obrázků funguje bez internetu; další věci nakreslí AI
  z Macu se say to draw na stejné Wi-Fi (na Macu klávesa **P**)
